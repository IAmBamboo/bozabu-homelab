Personal Project

Self-Hosted HomeLab & Infrastructure

Raspberry Pi Linux Docker Compose Cloudflare API TCP/UDP Tunneling GitHub Actions (CI/CD)

A fully self-hosted homelab running on Raspberry Pi hardware that hosts this website and a game server, using Docker containers and automated DNS management.

  • Built and managed an ARM-based self-hosted environment for a public website and game server using Docker Compose.
  • Automated DDNS with Cloudflare API to proactively maintain service availability across rotating IPv6 assignments.
  • Automated IPv6 monitoring and DNS updates via Cloudflare to ensure reliable service access while bypassing ISP CGNAT.
  • Configured SRV and AAAA DNS records to enable domain access and service discovery.
  • Implemented a CI/CD pipeline using GitHub Actions to automatically deploy website updates to Docker on Raspberry Pi.
